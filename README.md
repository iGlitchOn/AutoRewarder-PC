# AutoRewarder PC

**AutoRewarder by iGlitchOff** — Microsoft Rewards companion for **Windows**, **macOS**, and **Linux**.

This is the official PC app. Pair it with [AutoRewarder-Mobile](https://github.com/iGlitchOn/AutoRewarder-Mobile) on your phone.

## Download

Get the latest build from **[Releases](https://github.com/iGlitchOn/AutoRewarder-PC/releases)**:

- **Windows:** `AutoRewarder-Windows.zip` — extract and run `AutoRewarder.exe`
- **macOS / Linux:** run from source (`python AutoRewarder.py`) until native packages are published

Do **not** open the phone tunnel URL (`*.trycloudflare.com`) in a desktop browser. Use this PC app, and open that link only inside the official Android companion.
